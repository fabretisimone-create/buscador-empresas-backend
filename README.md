# 🔍 Buscador de Empresas Locais

Aplicação *full-stack* desenvolvida para prospecção de clientes B2B. A ferramenta identifica estabelecimentos comerciais em determinada cidade e categoria que **não possuem site cadastrado** no Google Maps, ajudando na identificação de oportunidades de vendas de serviços digitais.

🚀 **Acesse o projeto online:** [Buscador de Empresas](https://fabretisimone-create.github.io/buscador-empresas-backend/)

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (Fetch API) — Hospedado no **GitHub Pages**
* **Backend:** Node.js, Express, Google Places API — Hospedado no **Render**
* **Versionamento & Deploy:** Git, GitHub, GitHub Actions

---

## ⚙️ Funcionalidades

* Busca de empresas por Estado (UF), Cidade e Categoria.
* Integração direta com a API oficial do Google Places.
* Filtro automático de estabelecimentos sem presença web (sem URL cadastrada).
* Exibição de informações essenciais: Nome, Endereço, Telefone e Link do Google Maps.
